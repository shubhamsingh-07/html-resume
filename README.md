# HTML Resume Project

[![HTML5](https://img.shields.io/badge/HTML5-Resume-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A static, multi-page resume website built with HTML. The main page groups resume sections and links to separate hobbies and contact pages.

## Project Structure

```text
html-resume/
├── index.html
├── Hobbies.html
├── contact me.html
└── image/
    └── profile and certificate images
```

## Run Locally

No package installation, build step, or server is needed.

1. Clone or download the repository.
2. Open `index.html` in a modern browser.
3. Use the links on the page to open the hobbies and contact pages.

## Concepts Practiced

- HTML headings, paragraphs, lists, and links.
- Structuring a resume into education, experience, skills, certificates, and supporting pages.
- Linking local images and documents.
- Basic semantic page organization.

## Before Publishing

The HTML currently includes personal resume and contact content. Review it carefully and remove or update any private, outdated, or inaccurate information before sharing or deploying the site. Also ensure image and certificate files are appropriate to publish.

## Known Limitations

- This is a static HTML project without CSS styling, responsive layout, JavaScript, or a backend.
- The document structure and language metadata could be improved.
- Check the local image and page links after moving or renaming files.
